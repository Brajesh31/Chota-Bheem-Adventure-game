# Support

This is a small community game project and does not provide a hosted service or guaranteed response time.

## Questions and bug reports

Search existing [GitHub issues](https://github.com/Brajesh31/Chota-Bheem-Adventure-game/issues) first. Include your browser and operating system, the control sequence, expected result, observed result, and steps to reproduce. A screenshot or short clip can help with visual issues.

Do not include private information. For setup problems, describe how the page was opened and any browser console error. Report suspected security issues privately using [SECURITY.md](SECURITY.md), not in a public issue.

## Scope

The current project is a local static browser game. There is no online service, account system, or backend support. See [CONTRIBUTING.md](CONTRIBUTING.md) to propose a fix or documentation update.
