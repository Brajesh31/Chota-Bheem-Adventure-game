# Code of Conduct

This project welcomes contributions from people with different backgrounds and experience. Everyone participating in project spaces should help keep them respectful and constructive.

## Expected behavior

- Be considerate and patient.
- Discuss code and ideas without attacking or demeaning people.
- Give useful context in feedback and accept good-faith corrections.
- Respect privacy and do not publish personal data or credentials.
- Respect the rights and attribution of artists, musicians, and other creators.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, doxxing, repeated unwanted contact, deliberate disruption, sexualized attention without consent, and retaliation for raising concerns are not acceptable.

## Maintainer response

Maintainers may remove harmful content, pause a discussion, or restrict participation to protect contributors and keep the project useful. Responses should be proportionate and may range from a warning to temporary or permanent exclusion.

## Reporting

Report conduct concerns privately to the maintainer through the contact method on the `@brajesh31` GitHub profile. Include enough context to understand the issue while avoiding unnecessary sensitive information. For a security concern, use [SECURITY.md](SECURITY.md). If the concern involves the maintainer, use GitHub's platform reporting tools.

This policy applies to repository issues, discussions, pull requests, and other spaces where someone is representing or contributing to the project.
