# 🔒 Privacy Notice

## What the game does

Chota Bheem Adventures is a static browser game. The current application does not ask for a name, email address, account, location, or other personal information. It does not include application analytics, advertising scripts, an online leaderboard, or a backend service.

## Data stored by the game

The game keeps the current score and session state in browser memory only. It does not write gameplay information to local storage, cookies, or a remote database. Reloading or closing the page resets the session.

## Network requests

The Google Fonts request was removed. The game runtime is designed to use local HTML, CSS, JavaScript, images, GIFs, and audio from the same static site.

When deployed, the hosting provider may independently process ordinary HTTP request data in its server logs. That processing is controlled by the hosting provider, not by this game's JavaScript.

## Audio and browser permissions

The game requests local audio playback after the player starts. Browser site settings, tab mute, operating system volume, and autoplay restrictions can prevent sound. No microphone or camera access is requested.

## Children's privacy

The presence of a cartoon-themed game does not mean the project has been designed or audited as a child-directed service. It does not intentionally collect personal information. Do not add accounts, tracking, chat, behavioral analytics, or third-party SDKs without a separate privacy and legal review.

## Changes to data practices

Any future feature that collects, stores, or transmits information must update this document before release. Document the purpose, data categories, destination, retention, consent, security measures, and user deletion/reset options.

## Contact

For privacy questions, contact the maintainer through the GitHub profile linked from this repository. Do not include sensitive personal information in a public issue.
