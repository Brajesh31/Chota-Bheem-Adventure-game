## ✅ Accuracy policy

The game currently has no server, API, database, package manager, build pipeline, automated test runner, account system, or online leaderboard. Documents must not imply that those systems exist. Proposed functionality is clearly marked as future work.

The MIT grant in the repository root `LICENSE` applies to original code and documentation only. It excludes the bundled character art, animations, audio, and third-party branding whose reuse permissions are not established here.
