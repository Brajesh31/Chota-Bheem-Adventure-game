## Asset contribution rules

Before adding media, record creator/rightsholder, exact source and acquisition date, license or written permission, required attribution and modification restrictions, file type and dimensions/duration, approximate size, and whether redistribution inside a public Git repository is allowed.

Do not assume a file is reusable because it is already present. The existing branded character artwork, names, and audio may be protected by third-party rights. The root [LICENSE](../LICENSE) excludes these media assets from its MIT grant. Use [the asset-rights template](templates/asset-rights-record.md) before approving new assets.
