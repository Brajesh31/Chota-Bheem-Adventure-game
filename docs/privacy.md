# 🔒 Privacy and Data Handling

The public privacy statement is maintained in the root [PRIVACY.md](../PRIVACY.md).

## Current data flow

- No application account or profile exists.
- Score and session state are held in memory.
- No analytics, advertising, chat, or leaderboard integration exists.
- The application does not request camera, microphone, or location permissions.
- The game uses local assets and does not require third-party runtime scripts or fonts.
- The static hosting provider may have its own ordinary access logs and privacy policy.

Any future persistent or remote feature must update the root notice and document data purpose, categories, destination, retention, consent, security, and deletion/reset behavior.
