# FAQ

## How do I start?

Open `index.html` and click **Lets Run**.

## Which keys control Bheem?

Up jumps, Left moves left, and Right moves right. There are no touch controls in the current game.

## How is the score increased?

The game increments score when the bull passes near enough to count as a successful crossing without triggering the collision threshold.

## How do I play again after game over?

Reload the page. The current UI does not have an in-page restart control.

## Does the game save my score?

No. Score and game state are not stored after the page closes or reloads.

## Does it require a backend or internet?

No backend is required. Internet is used only for the Google Fonts stylesheet; images, GIFs, and audio are local repository files.
